# Browser-readable firmware

Generated by espOS's release-firmware.yml; do not edit or merge.

The images attached to this repository's releases, republished
because GitHub serves release downloads without the CORS header a
web page needs. The flasher reads them from raw.githubusercontent.com.

Rewritten as one commit on every publish. Holds the releases the
flasher can offer -- the three newest stable ones and up to two
newer prereleases; older ones are pruned here and remain
downloadable from their releases.
